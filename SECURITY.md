# Güvenlik Politikası

Güvenlik açığını herkese açık issue içinde paket içeriği, kimlik bilgisi veya kişisel veri paylaşmadan bildirin. Mümkünse GitHub'ın özel güvenlik bildirimi özelliğini kullanın.

NetWatch yakalamaları hassas veri içerebilir. `.pcap` dosyalarını paylaşmadan önce içeriğini inceleyin ve gerektiğinde anonimleştirin. Uygulama telemetri göndermez ve yakalanan paketleri belirtilen yerel `--save` yolu dışında kalıcılaştırmaz.
